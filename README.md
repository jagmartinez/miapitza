# Mia Pitza Restaurant System

Sistema multiempresa para compras, inventario, producción, menú, POS, caja,
cocina, facturación y reservaciones.

La guía de preparación y despliegue está en
`docs/PRODUCTION_READINESS_AUDIT_2026-07-12.md`.

Nunca use contraseñas predeterminadas. El script de recuperación exige usuario,
contraseña nueva de al menos 12 caracteres y `companyId`, y fuerza el cambio de
contraseña en el siguiente inicio de sesión.
